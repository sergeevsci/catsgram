# Catsgram 🐈📸

Учебный проект для изучения современных Java-технологий. **Catsgram** — это социальная сеть для обмена фотографиями котиков, построенная на базе Spring Boot, Maven и PostgreSQL.

## 🎯 Цели проекта
* Освоение сборщика проектов **Maven** и управление зависимостями.
* Изучение экосистемы **Spring Boot** (включая Spring Web и Spring Data JPA).
* Проектирование реляционных баз данных и работа с **PostgreSQL**.
* Разработка REST API по лучшим практикам.

---

## 🛠 Технологический стек

* **Язык**: Java 17 / 21
* **Сборщик**: Maven
* **Фреймворк**: Spring Boot
* **База данных**: PostgreSQL
* **Доступ к данным**: Spring Data JPA / JDBC Template
* **Инструменты**: Lombok, Postman (для тестирования API)

---

## 🚀 Функционал приложения

* **Пользователи**: регистрация, авторизация, профили котиков.
* **Публикации**: создание постов с картинками, описанием и хэштегами.
* **Лента активности**: просмотр свежих постов друзей и популярных публикаций.
* **Лайки и комментарии**: система оценки кошачьего контента.
